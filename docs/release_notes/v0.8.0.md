## 🚀 Overview

JASPER v0.8.0 represents a major evolutionary leap from a conversational assistant to a **truly autonomous, visually aware, and security-verified desktop companion**. 

This release introduces:
1. **Scoped Desktop Autonomy:** Surgical file chunk editing, sliced file inspection, and sandboxed terminal execution with multi-turn self-repair and natural intent routing.
2. **Low-Overhead Proactive Observation (`DeltaScreenWatcher`):** Background perceptual screen diffing (<1ms CPU, 0% GPU load) that notifies you when long-running jobs, builds, or downloads finish.
3. **Interactive Audit & Safety Timeline Drawer:** A slide-out, real-time safety ledger providing complete transparency, metric counters, expandable payload inspection, and JSON export for every permission check and tool execution.

## 🛠️ Key Capabilities & Features

### 1. Surgical Desktop Autonomy & Multi-Turn Self-Repair
- **High-Precision Sliced File Reading (`read_text_file`):**
  - Allows reading specific line ranges (`start_line`, `end_line`) with a 500-line limit to preserve context window tokens.
- **Surgical Chunk Replacement (`edit_file_chunk`):**
  - Eliminates destructive whole-file overwrites by requiring exact substring matching (`target_content`) before applying drop-in replacements (`replacement_content`).
  - Guarded by `Risk.WRITE` and mandatory human approval gates.
- **Scoped Shell Execution (`run_terminal_command`):**
  - Executes shell commands strictly within `workspace_root`.
  - Enforces a hard 30-second timeout and 4,000-character stdout/stderr truncation to prevent infinite loops.
  - Guarded by `Risk.EXECUTE` and mandatory human approval gates.
- **Natural Intent Routing:**
  - `CognitiveRouter` automatically routes natural coding, diagnostic, and task instructions (e.g., *"run the test script and fix any failures"*) into `CognitiveMode.AUTONOMOUS` without requiring explicit `/auto` prefixes.
  - Multi-prefix overrides supported: `/auto`, `/fix`, `/code`, `/task`, `/run`.
- **Multi-Turn Feedback & Auto-Fix Loop:**
  - Collects structured execution observations from tools, terminal output, and visual captures.
  - Re-injects feedback directly into subsequent planner and executor rounds with an expanded budget of 24 agent rounds and 6 autonomous iterations.

### 2. Low-Overhead Proactive Screen Observation (`DeltaScreenWatcher`)
- **Perceptual Screen Diffing:**
  - Downsamples screen captures to 32x32 grayscale buffers in memory via Qt native routines (<1ms execution time, 0% GPU load).
  - Calculates normalized mean absolute pixel differences (`compute_pixel_delta`).
- **Active Task & Window Awareness:**
  - Detects changes in active window titles and desktop processes alongside visual deltas.
- **Targeted Vision Verification:**
  - Local Vision LLM (`qwen3-vl:8b`) is only invoked when a meaningful visual delta (>3%) occurs, querying focused boolean prompts (`YES: <summary>` / `NO: <summary>`).
- **Safety & Privacy Invariants:**
  - Strictly zero continuous video streaming or screen recording.
  - Enforces a mandatory 10-minute maximum observation cap with fail-closed timeout notifications.
- **Desktop UX Integration:**
  - Start watching with `/watch [goal]` or the composer `👁` button.
  - Stop at any time with `/stopwatch`, `/unwatch`, or the composer `⏹` button.

### 3. Real-Time Audit Ledger & Timeline Drawer
- **Thread-Safe In-Memory Ring Buffer:**
  - Maintains the last 500 structured audit records in memory (`app/core/audit.py`), accessible in real-time.
- **Slide-Out Safety Drawer (`AuditTimelineDrawer`):**
  - Accessible via the header toggle `🛡️ Audit (N)` or the `/audit` chat command.
  - Live metric summary chips: `Total`, `Tools`, `Approved`, `Denied`.
  - Category filters (`All`, `Tools`, `Approvals`, `Security`, `Turns`) and live text search.
  - Expandable JSON payload inspector for auditing tool parameters, execution times, and return codes.
  - One-click JSON audit export (`QFileDialog`) for compliance and offline analysis.
- **Live Task Workspace Stream:**
  - Autonomous task steps stream live into `TasksWorkspace` as they occur.

## 🔒 Security & Safety Invariants

1. **Human-in-the-Loop Approval:** Every file write and shell command unconditionally triggers an un-ignorable modal approval prompt displaying exact command arguments and risk classifications.
2. **Recursive Argument Redaction:** Sensitive credentials, tokens, keys, and passwords are automatically scrubbed from approval modals and audit representations across all nesting depths.
3. **Fail-Closed Execution:** Denials, modal dismissals, cancellation requests, and window closes immediately abort execution and release resources safely.
4. **Strict Path Canonicalization:** All tool paths are resolved to absolute canonical paths against `workspace_root` to prevent directory traversal or symlink attacks.
